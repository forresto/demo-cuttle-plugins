# Example Plugin

A minimal Cuttle Parameter Plugin: one input, an SVG preview, and a Save button.
It outputs a star as blue score lines. It's the same as the empty example in Cuttle.

It uses the optional `v1.css` stylesheet for the Cuttle look, and
`cuttle.svgDataUrl` to save the SVG in `_image`. Both are explained in the
[main README](../README.md).
